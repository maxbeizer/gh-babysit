## Comparison links after creating a repository

Replace `OWNER` and `REPOSITORY` below with the generated repository's owner
and name. When preparing the first release, add its dated section and reference
link; then keep `[Unreleased]` comparing the latest release with `HEAD`.

```markdown
[Unreleased]: https://github.com/OWNER/REPOSITORY/compare/v0.1.0...HEAD
[0.1.0]: https://github.com/OWNER/REPOSITORY/releases/tag/v0.1.0
```

Do not leave these placeholders in a published changelog, and do not point a
generated project's comparison links back to this template repository.
